🏥 Emergency Doctor Simulator (응급실 의사 시뮬레이터)
응급실 의사가 되어 환자를 진료하고, 검사·치료·의뢰를 결정하며 성장하는 한국어 기반 브라우저 시뮬레이션 게임입니다.

환자의 증상과 활력징후를 확인하고, 제한된 시간 안에 적절한 진단과 처치를 선택하세요. 검사 결과를 기다리는 동안 다른 환자를 진료할 수도 있습니다. 흔한 질환부터 중증 응급질환까지 다양한 상황을 경험할 수 있습니다.
현재 버전: v31 · 장르: 의료 / 응급실 / 경영·전략 시뮬레이션 · 플랫폼: PC 및 모바일 웹 브라우저

GitHub Pages로 배포한 경우 아래 주소에서 플레이할 수 있습니다.

로컬에서도 별도 설치 없이 저장소의 index.html 파일을 브라우저로 열어 플레이할 수 있습니다.
✨ 주요 기능
- 응급실 진료: 환자 문진, 신체검사, 진단, 약물 처방, 처치, 전문과 의뢰 및 퇴원 결정
- 다양한 환자: 57개 진단과 CAT 1–5 중증도, 질환별 등장 빈도 및 중복 방지 보정
- 동적인 환자 상태: 시간 경과에 따라 변화하는 활력징후·상태와 치료 반응
- 검사 시스템: 혈액검사, 영상검사, 미생물검사와 시간차를 두고 도착하는 검사 결과
- 응급 영상검사: Emergency CT, MRI, Ultrasound의 즉시 결과 확인 및 적절성 평가
- 멀티태스킹: 검사 결과를 기다리며 다른 환자를 동시에 진료
- 시간 조절: 일시정지와 1× / 2× / 4× 진행 속도
- 진료 평가: 진단 정확도, 적절한 처치, 검사 효율, 의뢰·퇴원 결정 등을 반영한 점수와 평판
- 커리어 성장: 인턴부터 상급 의사 직급까지 경험과 평가를 쌓으며 승진
- 한국어 인터페이스: 주요 진료 화면과 튜토리얼을 한국어 중심으로 제공하며 의학 약어 병기
🩺 플레이 방법
1. 게임을 시작하고 응급실에 도착한 환자의 중증도와 활력징후를 확인합니다.
2. 문진과 신체검사를 통해 증상, 과거력 및 주요 진찰 소견을 파악합니다.
3. 필요한 혈액검사·영상검사·미생물검사를 주문합니다. 응급검사는 빠르지만 불필요한 사용 시 더 큰 감점이 발생할 수 있습니다.
4. 환자 상태에 맞게 진단, 약물, 처치를 선택합니다. 상태가 악화되기 전에 우선순위를 판단하세요.
5. 적절한 전문과에 의뢰하거나 퇴원을 결정합니다. 일부 질환은 별도 조건을 만족하면 GP 특별 퇴원이 가능합니다.
6. 근무가 끝나면 진료 결과와 점수·평판을 확인하고 다음 근무에 도전합니다.
게임 팁
- CAT 1–2 환자와 상태가 악화되는 환자를 우선 확인하세요.
- 검사를 많이 시행하는 것이 항상 좋은 결과로 이어지지는 않습니다.
- 검사 결과를 기다리는 동안 다른 환자를 진료하면 시간을 효율적으로 활용할 수 있습니다.
- 일부 응급질환은 영상검사 결과를 기다리지 않고 신속히 전문과에 의뢰하는 판단도 인정됩니다.
- 적절한 치료뿐 아니라 의뢰·퇴원 방향도 최종 평가에 영향을 줍니다.
